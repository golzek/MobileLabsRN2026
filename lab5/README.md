# Лабораторна робота №5 — Навігація у React Native з Expo Router

## Інструкція запуску

```bash
npm install
npm start
```

Відскануйте QR-код у додатку Expo Go (iOS / Android) або натисніть `a` для Android-емулятора, `i` — для iOS-симулятора.

---

## Реалізований функціонал

### Структура файлів (file-based routing)

```
app/
├── _layout.jsx
├── index.jsx
├── +not-found.jsx
├── (auth)/
│   ├── _layout.jsx
│   ├── login.jsx
│   └── register.jsx
└── (app)/
    ├── _layout.jsx
    ├── catalog.jsx
    └── details/
        └── [id].jsx

context/
└── AuthContext.jsx

data/
└── products.js
```

### Екрани

| Екран | Опис |
|---|---|
| Login | Поля Email / Пароль, кнопка «Увійти», посилання на реєстрацію |
| Register | Поля Ім'я / Email / Пароль / Підтвердження, кнопка «Зареєструватися» |
| Catalog | FlatList з картками товарів (фото, категорія, назва, ціна), кнопка «Вийти» |
| Details | Повна інформація про товар, отримана через `useLocalSearchParams` |
| Not Found | Повідомлення 404 з кнопкою повернення на головну |

### Авторизація

Стан зберігається у `AuthContext` (React Context API): `isAuthenticated`, `user`, `login()`, `register()`, `logout()`. Захищена група `(app)` перевіряє `isAuthenticated` у `_layout.jsx` та робить `<Redirect href="/login" />` для неавторизованих.

## Відповіді на контрольні запитання

### 1. Як реалізується перенаправлення неавторизованого користувача?

У файлі `app/(app)/_layout.jsx` зчитується `isAuthenticated` з `AuthContext`. Якщо значення `false` — компонент повертає `<Redirect href="/login" />`, що автоматично перенаправляє користувача ще до відображення будь-якого захищеного екрану.

### 2. Різниця між `<Link>` та `router.push()`

| `<Link>` | `router.push()` |
|---|---|
| Декларативний підхід (JSX-компонент) | Імперативний підхід (JavaScript-функція) |
| Підходить для навігації у розмітці | Використовується в обробниках подій |
| Підтримує `asChild` для кастомних компонентів | Зручний для умовної навігації |

### 3. Динамічні маршрути та отримання параметрів

Файл з іменем у квадратних дужках (наприклад `[id].jsx`) стає динамічним маршрутом. Expo Router автоматично парсить сегмент URL та передає його як параметр. Для отримання значення використовується хук:

```js
const { id } = useLocalSearchParams();
```

### 4. Чому стан авторизації у глобальному контексті?

Будь-який компонент у дереві може отримати стан без prop drilling. Стан зберігається між переходами між екранами. Логіка входу/виходу знаходиться в одному місці. Зміна `isAuthenticated` автоматично оновлює всі підписані компоненти, зокрема layout з редіректом.

### 5. Групи маршрутів і їх вплив на URL

Папки у форматі `(назва)` — це групи маршрутів. Назва групи не входить до URL-адреси:

- `app/(auth)/login.jsx` → URL: `/login`
- `app/(app)/catalog.jsx` → URL: `/catalog`

Це дозволяє логічно розділити екрани (публічні / захищені) та застосувати різні `_layout.jsx` без зміни маршрутів.
